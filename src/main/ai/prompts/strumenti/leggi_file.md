Legge un file trovato con `cerca_file` (o di cui conosci il percorso), con le stesse capacità di `leggi_allegato`: PDF (anche scansionati, che ricevi come immagini), Word, Excel, PowerPoint, OpenDocument, testi, HTML, immagini.

Parametri:

- `file`: il riferimento (f1, f2…) oppure il percorso completo.
- `pagina`: per un PDF, la pagina da cui partire.
- `da_carattere`: per gli altri file lunghi, il carattere da cui proseguire.
