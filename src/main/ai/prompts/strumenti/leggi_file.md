Legge un file trovato con `cerca_file` (o di cui conosci il percorso), con le stesse capacità di `leggi_allegato`: PDF, Word, Excel, PowerPoint, OpenDocument, testi, HTML, immagini.

Parametri:

- `file`: il riferimento (f1, f2…) oppure il percorso completo.
- `da_carattere`, `pagina`: per proseguire la lettura di un file lungo.
